How to install

  1. Click Download above and open the downloaded file.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. Windows shows this warning for programs it has not seen many times before; the installer is not yet digitally signed. To be sure your copy is genuine, compare its checksum (see below).
  3. Click Yes when Windows asks for permission. Amanat Backup is installed for all users in C:\Program Files\Amanat Backup.
  4. Follow the wizard: Next, choose whether you want a desktop shortcut, Install, Finish. The program starts, and the Dashboard's Getting started list guides you through your first backup.

Check that the download is genuine (optional)

Open PowerShell and run:

Get-FileHash "$env:USERPROFILE\Downloads\AmanatBackup-1.0.0-Setup.exe" -Algorithm SHA256

The Hash shown must be exactly the SHA-256 above (upper or lower case does not matter).

Updating

Close Amanat Backup, download the new version and run it. It installs over the old one and keeps your settings, backup jobs, history, licence and backups.

Uninstalling

Windows Settings → Apps → Installed apps → Amanat Backup → Uninstall. The program and its scheduled backups are removed. Your backups and settings are not deleted: the backups stay on your backup drives and the settings in %LOCALAPPDATA%\AmanatBackup, so installing again brings everything back.

For IT staff: silent and per-user installation
/VERYSILENT /SUPPRESSMSGBOXESSilent install for all users
/DIR="D:\Programs\Amanat Backup"Install into another folder
/CURRENTUSERInstall for the current Windows user only, without administrator rights
unins000.exe /VERYSILENTSilent uninstall (in the program folder)

Setup refuses to run while Amanat Backup or one of its scheduled backups is running; it never closes the program by force.
